
# Fusion Engine Editor

This would be a standalone editor for the "Fusion Engine". Improvements would be made overtime with different branches. The overall interface would be rendered
using IMGUI and OpenGL with GLFW being the base window manager.

## Features of the editor 
- Improved raycasting and object interaction (although more improvements would need to be made)
- Improvements to performance with lesser draw calls than previous editors
- Scripting system with object interaction (could possibly do object hirearchy within the explorer tab later)

## Features needed to be readded from the last editor
- Mesh based importing (and possibly more mesh file formats)
- Texture editor (could use a unified system with texture editing)
- Audio support using OpenAL
- Vertex editing (Possibly more with face editing and such)
- Texture system and addition of textures
